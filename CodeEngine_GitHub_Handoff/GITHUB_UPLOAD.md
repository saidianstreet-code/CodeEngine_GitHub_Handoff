# Как загрузить handoff CodeEngine на GitHub

1. Откройте свой GitHub-репозиторий CodeEngine.
2. Нажмите **Add file** → **Upload files** (или ссылку **uploading an existing file**).
3. Распакуйте ZIP-архив на компьютере.
4. Перетащите `HANDOFF.md`, `CHANGELOG.md` и `.gitignore` в область загрузки GitHub. Можно также загрузить `GITHUB_UPLOAD.md`.
5. Внизу страницы нажмите **Commit changes**.

## Когда будете загружать сам движок
- Лучше загрузить исходники проекта, сохранив структуру папок `src/`, `src/codeengine/` и `src/Main.java`.
- Не загружайте скомпилированную папку `out/`.
- Если исходники большие, можно загрузить ZIP проекта отдельным файлом, но для совместной работы удобнее хранить распакованные исходники в репозитории.
- После загрузки сообщите в чате ссылку на репозиторий. Если репозиторий приватный, ссылка сама по себе не даёт ChatGPT доступ к его содержимому: прикладывайте файлы сюда или используйте доступный подключённый инструмент для GitHub.
- В будущих чатах приложите актуальный `HANDOFF.md` и ZIP/исходники. Это надёжнее, чем полагаться только на память чата.

Не добавляйте пароли, токены GitHub, ключи API или другие секреты в репозиторий.
